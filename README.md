# sand.tegels
Этот проект представляет собой нейросетевую систему генерации текста, использующую Википедию в качестве основного источника данных для обучения. Система способна создавать уникальные текстовые последовательности на заданные темы, позволяя исследовать возможности текстового моделирования и обработки естественного языка.
